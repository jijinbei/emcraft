# Spherical cavity with a coated sphere

A closed sphere of radius 10 mm holding a ceramic sphere (εr = 4) of radius 5 mm, itself holding
a core (εr = 9) of radius 2.5 mm: an inclusion inside an inclusion. The three materials are
meshed as regions one inside the next — the coat's region has the core as a hole, as the
vacuum's has the coat — each interface tessellated once and frozen, and the regions joined node
for node. The lowest resonance (the TM11 triplet) against the three-layer closed form with
spherical Bessel functions carried through the layers.
