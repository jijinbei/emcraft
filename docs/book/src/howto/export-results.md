# Get results out

| You want | Command | In the window |
|---|---|---|
| S-parameters for a circuit simulator | `results.touchstone` | Results step → **Export** |
| S-parameters as numbers | `results.sparameters` | **Show the table** under the chart |
| a chart as a picture | `view.sparameters` | |
| a field picture | `view.field` | Field overlay → **Picture…** |
| a field animation | `view.animation` | Field overlay → **Animation…** |
| a far-field cut | `view.pattern`, `results.far_field` | the far-field page |
| eigenmodes | `results.eigenmodes` | the modes' table |
| everything, to open again | `file.save` | Save |

## Touchstone

```json
{"command": "results.touchstone", "params": {"path": "filter.s2p", "format": "ma"}}
```

Version 1 Touchstone, frequencies in GHz, real and imaginary parts (`ri`, the default) or
magnitude and angle (`ma`).

**Waveguide ports have no 50 Ω.** S of a waveguide port is a power wave of its mode, and the
file's `R 50` is nominal: the file is right for cascading with other blocks of the same guide,
not for reading impedances off it. Ports of lines with two conductors (coaxial, microstrip,
lumped ports) are referred to their `impedance`.

## Pictures

```json
{"command": "view.field", "params": {"path": "e.png", "frequency": 10, "plane": "h", "component": "ey", "theme": "dark"}}
```

Pictures are drawn by EMCraft itself, the same from the window and from a script, so a report
can be regenerated by rerunning the script. `theme` takes a built-in theme (`light`, `dark`,
`mono`, …) or the path of a theme file of your own;
[themes](https://github.com/jijinbei/emcraft/blob/main/docs/themes.md) sets the colours of
every chart.

## The project file

`file.save` writes one `.emcraft` file: the commands that built the model, the mesh, every
solve and, unless `"fields": false`, the fields. Opened again, it shows its results without
solving. With fields a project can be hundreds of megabytes; without them it is small, and
fields come back by running again. [The project file](../reference/project-file.md) describes
the format.

## Compare with a measurement

`results.import` reads a measured Touchstone file into the project, and `results.measured`
compares it with the solve on the same chart.
